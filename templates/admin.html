사용법 — 처음이시면 눌러 보세요

1. 이 화면을 휴대폰 첫 화면에 두기

  • 아이폰: 아래 가운데 [공유] → [홈 화면에 추가]
  • 갤럭시: 오른쪽 위 [⋮] → [홈 화면에 추가]
  • 비밀번호는 이 기기에서 한 번만 넣으면 됩니다.

2. 새 글 쓰기 (소식·글)

  1. [소식·글] → [+ 새 글 쓰기]
  2. 제목: 지역 + 무엇 (예: 청풍호 독채, 겨울에도 따뜻한가요?)
  3. 요약: 이 글의 답을 한두 문장으로. 검색 결과에 그대로 보입니다.
  4. 태그: 쉼표로 (예: 청풍호, 독채펜션)
  5. 본문: [소제목]은 질문으로, 바로 아래 첫 문장에 답을 적으세요.
  6. [저장] → 1~2분 뒤 홈페이지 소식에 올라갑니다.

3. 쓴 글 고치기

  • [소식·글] 목록에서 글을 누르거나
  • 홈페이지에서 글을 보다가 오른쪽 아래 「이 글 수정」을 누르세요.

4. 사진

  • 글 안에 넣기: 넣을 자리를 한 번 누르고 → [사진 넣기]. 여러 장 한 번에 됩니다. 크기는 자동으로 줄어듭니다.
  • 빼기: 사진을 눌러 빨간 테두리가 생기면 → [고른 사진 빼기]
  • 첫 화면 사진: [첫 화면] → [사진 바꾸기]. PC용은 가로가 넓은 사진, 폰용은 세로 사진.
  • 사진첩: [사진첩]에서 공간별로 더하고 빼고 순서를 바꿉니다.

5. 공지·연락처·요금

  • [공지 한 줄]: 문구를 쓰고 「공지 보이기」를 켜면 첫 화면 아래에 나옵니다. 끄면 사라집니다.
  • [연락처·시간]: 전화와 입실·퇴실을 바꾸면 홈페이지 전체와 검색 정보가 같이 바뀝니다.
  • [요금]: 요일별 1박 요금과 추가 요금. 빈 칸은 「문의」로 보입니다.

6. 검색에 잘 걸리는 요령

  • 숫자로 쓰기 — 가격, 시간, 인원, 거리
  • 실제 사진 쓰기, 지어낸 후기 쓰지 않기
  • 글 하나에 주제 하나

7. 실수했을 때 · 안 될 때

  • 방금 한 것 취소: [되돌리기]. 저장 전이면 [목록]으로 나가면 바뀐 것이 버려집니다.
  • 「저장 실패」: 인터넷을 확인하고 [저장]을 다시 누르세요.
  • 저장했는데 안 바뀜: 1~2분 기다린 뒤 홈페이지를 새로고침(휴대폰은 아래로 당기기)
  • 비밀번호가 안 맞음: 관리하는 분께 새 비밀번호를 받으세요.

8. 비밀번호 관리 (관리하는 분)

  • 비밀번호는 카톡 단체방에 올리지 마세요.
  • 직원이 그만두면 메뉴 아래 [비밀번호 정하기·바꾸기]로 바꾸세요. 그러면 모든 사람이 새 비밀번호를 넣어야 합니다.
  • 바꿀 때는 이 홈페이지 전용 GitHub 토큰이 한 번 필요합니다. 모르시면 만든 곳에 문의하세요.
